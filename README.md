# Smart Router Gatekeeper · 软路由设备准入认证与全球实时云控系统

一套专为 **ImmortalWrt 24.10 / OpenWrt (`aarch64`)** 打造的零依赖、单文件设备准入控制（Captive Portal）与全球实时云控管理面板。同时内置 `--mock` 本地仿真模式，可在任意 Windows / macOS / Linux 电脑零路由器环境预览与体验全部功能。

---

## 三分钟大白话上手教程

> **原理一句话**：核心程序直接装在你的软路由（`192.168.6.1`）里 24 小时开机运行。不管你换了哪台新电脑、在家里还是出门在外，打开浏览器就能实时看手机和断网，不需要每台电脑单独装监控客户端！

### 第 1 步：在任意新电脑下载开箱即用包
1. 打开本项目的 GitHub **Releases** 页面下载 **`SmartRouterGatekeeper-Windows-Kit.zip`** 并解压（里面已经编好了软路由程序和 Windows 程序，不用装 Go 或任何编程工具）。
2. 如果只是想先在电脑上体验效果：直接双击 **`双击启动-本地模拟体验.bat`**，会自动弹出浏览器（默认密码 `admin123`）。

### 第 2 步：把程序一键装进软路由（只需操作 1 次）
1. 确保你的电脑连着软路由网络，双击 **`双击部署-一键安装到软路由.bat`**。
2. 敲回车确认软路由 IP（默认 `192.168.6.1`），再输入你想设的后台登录密码，接着输入软路由 SSH 的 `root` 密码回车即可全自动安装并设为开机自启。

### 第 3 步：在家用电脑/手机实时管手机
- 家里任何连网的电脑或手机，打开浏览器访问 `http://192.168.6.1:8088` 输入密码即可：
  - **新手机连 Wi-Fi**：手机会自动弹窗要求输入「姓名/设备代号」申请联网，你这边立刻响铃提示，点「批准连网」才放行。
  - **快捷备注**：点击设备名字即可改备注（支持一键点 `电脑` / `手机` / `平板` 标签）。
  - **查看上网时间和时长**：名称下方直接显示何时联网；点击绿色「已连时长」胶囊可在 **`分钟 → 小时 → 天`** 之间循环切换。
  - **一键断网 / 定时断网 / 一键恢复**：点「断网」立即掐断所有国内和代理流量；点「定时 ▾」可选断网几分钟或几小时，倒计时结束自动恢复联网；也能随时手动提前恢复。

### 第 4 步：出门在外（用手机 4G/5G 或任何外面电脑）远程看和控
- **零配置免费方案（推荐）**：在后台顶栏点 **「远程访问」→「一键开启外网访问」**，系统会通过 Cloudflare Tunnel 自动生成一条加密的 `https://xxxx.trycloudflare.com` 公网网址。把这个网址存到手机或微信，无论你在全球哪台电脑打开它、输入管理员密码，都能实时看到家里每台手机的网速和状态，随时远程断网或放行！
- **固定不变域名方案（可选）**：如果你希望网址重启路由器也不变，可在 Cloudflare Zero Trust 免费创建隧道获取 Token，填入后台「设置」中并选择「固定域名隧道」开启。

## 核心技术特性

1. **防 PassWall 绕过的独立 `nftables` 准入引擎**
   - 独立维护 `table inet gatekeeper`，不污染系统 `fw4` 与 PassWall 规则。
   - `prerouting` 链以 `-170`（filter）与 `-160`（nat）高优先级抢在 PassWall `TPROXY (-150)` / `REDIRECT (-100)` 与 `dnsmasq` 之前生效，彻底阻断未授权设备的国内/外网/代理/DNS/IPv6 流量。
   - 内置 Captive DNS（`:5354`）与 Captive Portal（`:8089`），手机连 Wi-Fi 自动弹出登录页。
   - 断网/顶替时自动执行 `conntrack -D` 秒级掐断存量长连接。
   - 强制防锁死兜底：自动保护网关 `192.168.6.1`、管理主机 IP/MAC 白名单及 SSH `22` / 管理端口 `8088`。
2. **极速无卡顿管控大屏（`:8088`）**
   - 纯 Go 标准库 + `//go:embed` 内嵌静态资源，Keyed 增量 DOM 复用 + 0ms 乐观更新。
   - 支持并发上限锁与超限一键顶替最早接入设备。
   - 支持按状态筛选、按联网时间/已连时长/网速/备注/IP 升降序排列及实时搜索。

## 开发者命令行操作

```powershell
# 编译 Windows amd64 与 ImmortalWrt linux/arm64 静态二进制
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1

# 启动本地仿真模式
.\dist\gatekeeper-windows-amd64.exe --mock --port 8088 --portal-port 8089 --data-dir .\data

# 一键部署到 ImmortalWrt (192.168.6.1)
powershell -ExecutionPolicy Bypass -File .\scripts\deploy_to_immortalwrt.ps1 -RouterIP 192.168.6.1 -Password "您的管理密码"
```
