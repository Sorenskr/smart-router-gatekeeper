极简使用说明

        
      

      

        
0. 准入管控总开关：顶部可一键切换「管控已开启 / 自由放行模式」。关闭后所有新连 Wi-Fi 的手机直接上网，无需输入昵称且不受并发数或断网拦截限制。

        
1. 给设备备注（电脑/手机等）：点击任意设备名称或编辑图标，可直接输入备注或一键点「电脑」「手机」「平板」标签保存。

        
2. 查看联网时间与时长：设备名称下方显示「何时联网」；点击绿色的「已连时长」胶囊即可在 分钟 → 小时 → 天 之间循环切换。

        
3. 一键断网与定时断网：点「断网」立即切断全部国内和代理流量；点「定时 ▾」可设置断网几分钟或几小时，倒计时结束自动恢复联网；点「恢复联网」可随时提前放行。

        
4. 防锁死保护：将您常用的电脑设为「白名单」，它不会占用手机并发名额，也永远不会被误断网。
